# 需求修订摘要与待确认事项
**版本：** 0.3 · **日期：** 2026-10-21 · **范围：** 更新设计文档，不开发或部署应用

## 1. 本次采用的主规则
您开头明确要求“client 不需要给平台付 commission fee，由施工方向平台支付”，因此所有现行文档统一为：

**客户向平台付费 €0；由施工企业付平台服务费。**

正文中“客户付 €1、公司免费”仅作为商业模式对比保留，不成为默认功能，也不新增客户支付入口。

## 2. 建议的收费定义——需要确认后才实施
建议施工企业先免费查看需求，决定合适后，**首次成功向该客户展示一条意向报价时，支付 €1（示例按含税价）**。不是看一眼就收费，也不是按最终施工金额抽成；同企业、同需求的重复打开、编辑和正常联系不再次收费。

收费方是明确要求；“首次成功报价展示”这个收费时点、是否含税及直接 €1 支付是本次实施建议，尚不视为您已批准。原先强制 €10 充值钱包被移出当前 MVP，可作为以后降低支付手续费的可选研究。

平台不监控线下成交，因此不建议当前采用“成交后按比例抽佣”。已成功展示的报价即使未获单，也不自动退款；付款后因需求关闭、到期或实质变更而无法展示的，则走全额平台费退款。平台故障、重复扣费和证实的无效需求另有退款处理。

## 4. 操作和隐私
客户填写简短描述、postcode/city、几张可选照片；邮箱用于安全管理，非强制账号注册。企业注册自报联系方式、网站（如有）、工种和服务距离。

默认由客户主动联系企业。客户也可明确选择“允许已提交报价的企业联系我”，并选择公开邮箱/电话。必须解释此时受众不是最多三家；客户可撤销未来展示，已被抄录的信息无法远程收回。完整 postcode 和地址不直接展示在通用需求列表里。

企业看不到竞争者名单、报价或参与数量；客户能分页查看自己的全部合资格报价。客户随时关闭，关闭后不接收新报价、提醒或新的回拨信息展示。

平台不做常规施工质量认证、现场监督或工程款处理；但不能把“信息平台”写成免除自身数据安全、平台费、隐私、违法内容通知等责任。投诉先记录、核查必要事实和采取适当提醒/限制，不自动公开未经证实的指控。

## 5. “三个月”建议精确定义
建议以**首次公开发布 + 三个日历月**为不可自动延长的截止时间，不是“最后活动后 90 天”。修改、关闭后重开、注册账号、新增报价都不重置。

截止时立即禁止访问；建议在线主存储/图片版本在 24 小时内自动清理，隔离备份在最长 30 天滚动过期，恢复备份前先应用删除记录。上线前需要您确认这种技术时限表述。

不能笼统承诺一切资料三个月全部消失：平台服务费最小会计/发票资料可能须更长期依法保存；仍在使用的企业账号/提醒偏好也有不同用途。不能因此保留整份客户照片、地址或报价内容。相关例外、投诉证据范围和期限须透明说明并由专业人员确认。

## 6. 仍需决策
1. **正式名称**：先保留 Work Platform 工作名，不默认 HoutMatch 已适合多工种。可研究 NoordKlus、KlusDichtbij、KlusKompas 等创意方向，但未查商标/域名，也不代表可注册。
2. **试点边界**：暂按 Groningen 和 Fryslân 两省理解，Drachten 包含在 Fryslân 试点；需确认 Groningen 是城市还是全省，以及最终 postcode/市镇白名单。
3. **收费时点/税费**：确认上述 €1 首次成功报价展示方案、含税口径、退款条款和直接支付。
4. **商户/结算账户**：应属于实际运营平台的合法主体及获批商业账户，不是助手账户，也不是随意共享的私人账户。
5. **位置服务**：推荐先评估 PDOK 荷兰公共地理服务降低现金成本；若选 Google，需要独立商户项目、配额/预算及缓存/归属条款审核。
6. **管理/推广预算**：零付费广告可以先做，服务器、邮件、支付手续费和人员工作不能假定为零。自动提醒仅发给已确认订阅、匹配地区/工种/半径的企业。
7. **Google Ads**：文档给出单独审批的 €100 探索预算示例，并非已建立广告活动或保证盈利；日均预算不是简单硬日上限。

上述事项作为 G0/G2 决策列入清单，本次不等待所有商业细节确定就整理文档，也不在未经确认时替您开户、投放或上线。

## 7. Stripe 支付模块补充
根据您建议考虑 stripe-node，现将 **Stripe 托管 Checkout + 官方 Node.js SDK** 设为首选候选，npm 包名为 `stripe`，仅用于服务端。桌面、Android 和 iPhone PWA 共用同一支付后端，不需为当前阶段增加手机原生支付 SDK。

保留客户免费、施工方付平台费的规则。平台只收自己的报价展示服务费，不代收工程款，因此当前不需要 Stripe Connect、施工方分账或订阅。正式选型仍待商户主体、支付方式、费率及测试确认，本次没有安装 SDK、开户或启用真实收款。

已补充原始请求体验签、重复/乱序/异步通知、服务端核验、一次性报价展示、退款和对账设计。支付成本按 [Stripe 荷兰公开费率](https://stripe.com/nl/pricing)（2026-10-21 核对）重新测算：iDEAL 每笔 €0.29；€1 服务费即便使用 Stripe 仍需验证可持续性，不能把 SDK 当作免手续费方案。详见[支付设计](08-payments-and-economics.md)和[技术设计](05-technical-design.md)。
