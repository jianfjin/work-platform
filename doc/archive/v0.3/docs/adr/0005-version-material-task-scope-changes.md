# Version material task changes and refund unpublished old-scope payments

On 21 October 2026 the founder confirmed that material task edits, such as changing two doors to five, create a new scope revision: a captured payment for an unpublished offer on an older revision receives a full refund instead of publishing that offer. Already published offers remain visible with a scope-change label and can be edited free, without an automatic refund or extra publication fee. This lets clients correct their request while making changes explicit, without silently treating an old offer or payment as approval of different work.

The payment outcome and offer-publication order determine which rule applies; merely completing checkout is not offer publication. An unpaid attempt does not require a refund, but it cannot later publish against an obsolete revision; a late capture follows the same refund rule. Material edits never renew task expiry, and exceptions for substantiated invalid listings remain part of the separate refund-policy discussion.
