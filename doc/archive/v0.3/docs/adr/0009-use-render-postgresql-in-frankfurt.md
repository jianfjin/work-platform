# Use Render PostgreSQL in Frankfurt

On 22 October 2026 the founder confirmed paid Render PostgreSQL in Frankfurt after comparing it with Supabase, favoring the existing relational design and included point-in-time recovery. Keep the TypeScript application on Cloudflare Workers and connect through Hyperdrive with application query caching disabled, using Render's external TLS endpoint and reviewed source-IP restrictions. This selects the database provider and region; compute/storage/version, connection qualification, recovery/retention evidence and operating costs remain implementation and launch work, with no resources provisioned; see the [deployment comparison](../../doc/18-cloudflare-vs-render.md).
