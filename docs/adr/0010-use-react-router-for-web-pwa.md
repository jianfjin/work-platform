# Use React Router framework mode for the Web/PWA

On 22 October 2026 the founder confirmed React Router framework mode with React, Vite and server rendering for the Web/PWA, choosing its routing/form model and documented Cloudflare Workers deployment path over the earlier Next.js candidate. Hono remains the HTTP API layer, and UI loaders/actions must use the same authorization-checked application services rather than duplicate task, offer or billing rules. Qualify exact versions, SSR/API/asset dispatch, cookies, private-response handling, PWA behavior and scheduled handlers during foundation work; no build or deployment has run, and the documented Cloudflare Vite integration does not currently support framework SPA mode or prerendering; see [architecture](../../doc/04-architecture.md).
